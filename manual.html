คู่มือการใช้งาน

1. วิธีเข้าใช้งาน

  1. เปิดเว็บเบราว์เซอร์ (Chrome, Firefox, Safari, Edge)
  2. พิมพ์ URL ของระบบในช่อง Address Bar
  3. กด Enter เพื่อเข้าสู่หน้าแรกของระบบ

2. การใช้งานเครื่องคำนวณ

  1. คลิกที่เมนู "เครื่องคำนวณ" หรือปุ่ม "เริ่มใช้งานเครื่องคำนวณ" ที่หน้าแรก
  2. กรอกตัวเลขในช่อง "ตัวเลขที่ 1"
  3. กรอกตัวเลขในช่อง "ตัวเลขที่ 2"
  4. คลิกปุ่ม "คำนวณ" เพื่อดูผลลัพธ์
  5. ผลลัพธ์จะแสดงในกล่องด้านล่าง
เคล็ดลับ: สามารถกดปุ่ม Enter บนแป้นพิมพ์แทนการคลิกปุ่มคำนวณได้

3. การล้างค่า

  • คลิกปุ่ม "ล้าง" เพื่อล้างข้อมูลทั้งหมดและเริ่มคำนวณใหม่

4. การใช้งานบนมือถือ

  • ระบบรองรับการแสดงผลบนมือถือโดยอัตโนมัติ
  • เมนูจะถูกย่อเป็นปุ่ม ☰ กดเพื่อเปิดเมนู
  • สามารถใช้งานทุกฟังก์ชันได้เหมือนกับคอมพิวเตอร์

5. ข้อควรทราบ

  • ระบบรองรับทั้งจำนวนเต็มและทศนิยม
  • ผลลัพธ์จะแสดงในรูปแบบตัวเลขที่อ่านง่าย (มีเครื่องหมายคั่นหลักพัน)
  • หากกรอกข้อมูลไม่ครบ ระบบจะแจ้งเตือนให้กรอกให้ครบถ้วน

6. การติดต่อ

หากพบปัญหาในการใช้งาน กรุณาติดต่อฝ่าย IT ภายในองค์กร
